# Workflow — Revoir du code

1. Définir le périmètre, les risques et les conventions applicables.
2. Code Reviewer examine lisibilité, comportements, erreurs, dette et maintien de l'architecture.
3. Testing Engineer examine la couverture et les cas de régression ; Cybersecurity Specialist intervient pour une frontière de sécurité.
4. Rendre les constats classés par priorité, avec fichier/zone concernée, impact et correction proposée. Ne pas modifier le code sans mandat de correction.
