# Workflow — Développer une fonctionnalité

1. Le Master Agent limite la sélection aux rôles nécessaires : produit/UX, frontend, backend, données ou tests selon le périmètre.
2. Définir l'exigence, les permissions, les critères d'acceptation et les états d'erreur.
3. L'architecte intervient si la fonctionnalité modifie une frontière de service ou une décision existante.
4. Les développeurs réalisent la modification dans le dépôt applicatif, avec les tests pertinents.
5. Le Testing Engineer vérifie le scénario nominal, les erreurs et les régressions. Le Master Agent consolide les résultats et les décisions restantes.
