# Vue d'ensemble HOME AI

HOME AI est un projet personnel d'assistant domestique de type Jarvis. L'objectif est une application web responsive et sécurisée, un dashboard personnalisé, une interface conversationnelle, des rappels/calendriers, une mémoire personnelle et partagée, des commandes vocales et des automatisations Home Assistant.

L'architecture envisagée est hybride : Home Assistant et la Raspberry Pi assurent le contrôle local ; l'IA peut être locale ou cloud selon le besoin. Les scènes domestiques déterministes doivent rester utiles lorsque les services cloud sont indisponibles.

Contraintes actuelles : appartement loué, achats progressifs, budget matériel indicatif de 200–250 €, Raspberry Pi probablement modèle 4 à inventorier, accès extérieur sécurisé requis. Les choix Vue 3, Node.js, TypeScript, SQLite et Docker sont des hypothèses à confirmer.
