# Workflow — Comparer des technologies

1. Software Architect cadre la décision, les contraintes et les critères.
2. Technology Researcher documente les options avec sources primaires.
3. Les spécialistes concernés évaluent intégration, sécurité, coûts et exploitation.
4. Produire une étude puis une décision technique explicite ; ne pas confondre recommandation et choix validé.
