# Workflow — Concevoir une fonctionnalité

1. Partir du besoin produit et du profil autorisé à utiliser la fonction.
2. UX Designer définit le parcours, les exceptions et les priorités d'information.
3. UI Designer propose la hiérarchie et les états visuels ; Design System Specialist garantit les composants et tokens réutilisables.
4. Frontend Developer valide la faisabilité et les comportements responsive.
5. Livrer une spécification implémentable : écrans, états, règles d'accès et critères d'acceptation.
