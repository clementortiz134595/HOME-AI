# Modèles

Chaque nouveau sous-projet part de [ce modèle de dossier](sous-projet/README.md). Les ADR utilisent [ce modèle](adr.md).

Les fichiers sont volontairement courts au départ. Un dossier ne devient détaillé que lorsqu'il porte une décision, une expérimentation, une interaction ou une livraison réelle.
