# Modèle de dossier de sous-projet

```text
mon-sous-projet/
├── README.md                 # objectif, responsable, statut et liens
├── specification.md          # besoin, périmètre, critères d'acceptation
├── etudes/                   # comparatifs, faisabilité, prototypes
├── architecture/             # dossier technique et ADR
├── diagrammes/               # flux, séquences, composants, données
├── interactions/             # parcours, états, messages et cas d'erreur
├── design/                   # maquettes, tokens ou règles visuelles
├── tests/                    # stratégie, preuves et scénarios
└── code/                     # code seulement lorsque nécessaire
```

Chaque dossier actif garde un index pour ces sections. Les liens croisés permettent de retrouver l'exigence, le choix, l'implémentation et la preuve de test.
