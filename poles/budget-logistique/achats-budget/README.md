# Achats & budget

- Statut : suivi initial prêt
- Objectif : conserver un budget disponible exact et lier chaque dépense à un équipement, une décision et une preuve d'achat.

Le journal de référence est le classeur du pôle. Les achats ont les statuts `À étudier`, `Approuvé`, `Commandé`, `Reçu` ou `Annulé`.
